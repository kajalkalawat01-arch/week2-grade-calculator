# Student Grade Calculator

## Project Description
The Student Grade Calculator is a Python project that calculates student marks, percentages, and grades.

## Features
- Add student details
- Enter marks for three subjects
- Calculate total marks and percentage
- Assign grades based on percentage
- Display student results
- Calculate class average, highest and lowest percentages
- Search for a student
- Save results to a text file
- Handle invalid input using try-except

## Technologies Used
- Python
- Lists and dictionaries
- Functions
- Loops and conditional statements
- File handling
- Exception handling

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python grade_calculator.py
```

## Project Files
- `grade_calculator.py` - Main Python program
- `test_students.txt` - Sample test data
- `results_sample.txt` - Sample student results
- `README.md` - Project documentation
